# Shared contract snapshots

Exact JSON Schema files from `nordicintel-schemas`, commit `997a9a32f102bde50d93c83ef7ceefc320be0ed7`, collection version `1.0.0`.

The source repository owns these definitions. Update the snapshots together when adopting a contract change; do not edit them independently here. They are bundled for offline validation and do not require a sibling checkout or published URLs at runtime.

`../datasets.py` and `../dimensions.py` implement the typed models. Completed documents are checked against these schemas; cross-field ordering and identity are validated by the models.
